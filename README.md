This is the Site Characterization Database for the New Zealand National Seismic Hazard Model (NSHM). Information on the New Zealand NSHM can be found on the [GNS website](https://www.gns.cri.nz/research-projects/national-seismic-hazard-model/) and model hazard data can be found on the [NSHM webapp](https://nshm.gns.cri.nz/).

This repository contains the Site Characterization Database, supporting data, and documentation.

The documentation is published on `github-pages`.
