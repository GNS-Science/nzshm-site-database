# Project Layout

All relevant project files are in the `nzshm_site_database` directory.

## data

The site database itself is a csv file `sitedb.csv`

Supporting data for each site is contained within the `sites` directory. Each station has its own sub-directory below `sites`. This is where any supporting data and metadata are stored.

## templates

A directory of documentation templates used to build the website.

## scripts

Python scripts used to build documentation from the templates in `docs`
